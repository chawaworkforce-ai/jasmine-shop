สำหรับแอดมิน · ข้อมูลจากระบบฝากซื้อสินค้า

กำลังเชื่อมต่อไลน์…
🔁 ส่งไปลงหนี้ในระบบกู้ยืม (ทั้งชุด)
ใช้ใน Chrome บนแท็บเล็ตเครื่องที่มีระบบกู้ยืม · ① เปิดระบบกู้ยืม → ② ส่งรายการ → กดลงหนี้ที่แท็บระบบกู้ยืม → กลับมาหน้านี้ หน้านี้บันทึกเลขหนี้และตรวจให้เอง
⚠️ หน้านี้เปิดอยู่ในไลน์ — ส่งไปลงหนี้ทั้งชุดได้เฉพาะใน Chrome (ระบบกู้ยืมอยู่ใน Chrome) คัดลอกลิงก์ แล้วเปิดแอป Chrome วางในช่องที่อยู่ด้านบน
ทางสำรอง: วางเลขหนี้ทั้งชุด (ใช้เมื่อส่งข้ามแท็บไม่ได้)
วางข้อความเลขหนี้ที่คัดลอกจากระบบกู้ยืมทั้งก้อน แล้วแตะตรวจและบันทึก · หน้านี้ตรวจทีละใบกับข้อมูลล่าสุดก่อนบันทึก แล้วให้คัดลอกผลตรวจกลับไปวางในระบบกู้ยืม
